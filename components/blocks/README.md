# Blocks

Composed sections: marketing, auth, app and motion blocks. Every file is MIT and is what `npx stampui add` copies into your project. Linked names open the live preview on stampui.com.

| Block | Slug | Description |
|---|---|---|
| Animated Counter | `animated-counter` | Number that animates to its target value with easing on mount. |
| [Announcement Bar](https://stampui.com/blocks/piece/announcement-bar) | `announcement-bar` | Site-wide dismissible notification banner for announcements, promotions, and alerts. |
| [Changelog Feed](https://stampui.com/blocks/piece/changelog-feed) | `changelog-feed` | Vertical timeline changelog with versioned entries, date, tag badges, and feature descriptions. |
| [Cookie Consent](https://stampui.com/blocks/piece/cookie-consent) | `cookie-consent` | GDPR cookie consent banner with accept, decline, and customize options. Sticks to the bottom of the viewport. |
| [CTA Banner](https://stampui.com/blocks/piece/cta-banner) | `cta-banner` | Full-width call-to-action banner with headline, description, and primary/secondary action buttons. |
| [Email Login](https://stampui.com/blocks/piece/login-email) | `login-email` | A standard email and password login card with remember me checkbox and forgot password link. |
| [Empty State](https://stampui.com/blocks/piece/empty-state) | `empty-state` | Centered empty-state block with icon, title, description, and optional action button. |
| [Error Page](https://stampui.com/blocks/product/error-page) | `error-page` | Minimal status page for 404, 403, 500 and 503 maintenance: mono code, title, one sentence and two actions. |
| [FAQ Accordion](https://stampui.com/blocks/piece/faq-accordion) | `faq-accordion` | Animated expand/collapse FAQ list with plus/minus icons and optional section heading. |
| [FAQ Section](https://stampui.com/blocks/marketing/faq-section) | `faq-section` | Two-column FAQ with an accessible accordion and matching FAQPage JSON-LD built from the same items. |
| [Feature Comparison](https://stampui.com/blocks/piece/feature-comparison) | `feature-comparison` | Side-by-side plan comparison table with check/cross feature rows and highlighted recommended tier. |
| Feature Grid | `feature-grid` | Responsive icon + title + description feature grid. 2, 3, or 4 column layouts with optional eyebrow and headline. |
| [Forgot Password](https://stampui.com/blocks/piece/forgot-password) | `forgot-password` | A password reset request form featuring inline success alerts. |
| [Gradient Text](https://stampui.com/blocks/piece/gradient-text) | `gradient-text` | Text with a configurable CSS gradient fill. Supports any heading level and direction. |
| Grid Wave | `grid-wave` | 4×4 dot grid with diagonal ripple wave animation. |
| [Hero Centered](https://stampui.com/blocks/marketing/hero-centered) | `hero-centered` | Centered hero with headline, copyable install command and CTAs. Default variant adds an eyebrow and highlights; the minimal variant puts the CTA and command side by side over a faded line grid. |
| Hero Section | `hero-section` | Full-width landing page hero with headline, subtext, primary and secondary CTAs, and optional eyebrow badge. |
| Loading Card | `loading-card` | Card skeleton with shimmer animation for loading states. |
| Loading Dots | `loading-dots` | Three dots that bounce sequentially as a loading indicator. |
| [Metrics Grid](https://stampui.com/blocks/piece/metrics-grid) | `metrics-grid` | KPI card grid with value, label, trend direction, and percentage change indicator. |
| [Newsletter Inline](https://stampui.com/blocks/marketing/newsletter-inline) | `newsletter-inline` | One-line opt-in email capture: a sentence of copy, email input and button, with inline success and error states and a honeypot field. Posts to your endpoint or calls onSubmit. |
| Orbit Trail | `orbit-trail` | Three dots orbiting a center point at different radii and speeds. |
| Pricing Section | `pricing-section` | A modern, data-driven pricing section for SaaS products. |
| Progress Ring | `progress-ring` | SVG circular progress ring with animated fill and percentage label. |
| Registry Explorer | `registry-explorer` | A searchable, filterable block registry browser with sidebar navigation. |
| Signal Arc | `signal-arc` | Concentric rings that expand and fade like sonar pulses. |
| [Simple Signup](https://stampui.com/blocks/piece/signup-simple) | `signup-simple` | A single-step registration form with name, email, password, and terms checkbox. |
| [Site Footer](https://stampui.com/blocks/piece/site-footer) | `site-footer` | Multi-column site footer with brand logo, navigation links, social icons, and copyright line. |
| [Social Proof Bar](https://stampui.com/blocks/piece/social-proof-bar) | `social-proof-bar` | Logo strip with star rating, user count, and trusted-by label for landing page credibility. |
| [Stat Cards](https://stampui.com/blocks/piece/stat-cards) | `stat-cards` | A 2×2 KPI overview card with metric values, trend arrows, and period comparison badges. |
| Stats Strip | `stats-strip` | Animated count-up metrics row. Strip layout (bordered, full-width) or grid layout. Numbers animate on viewport entry. |
| [Team Grid](https://stampui.com/blocks/piece/team-grid) | `team-grid` | Responsive team member card grid with avatar, name, role, bio, and social links. |
| [Terminal Block](https://stampui.com/blocks/piece/terminal-block) | `terminal-block` | An interactive terminal emulator with pre-defined command responses, command history navigation, and auto-scroll. |
| [Testimonials Wall](https://stampui.com/blocks/piece/testimonials-wall) | `testimonials-wall` | Masonry-style testimonial quote wall with avatar, name, role, and star rating. |
| Typewriter Text | `typewriter-text` | Text that types, pauses, and deletes itself in a looping typewriter effect. |
| Usage Card | `usage-card` | Display API usage and subscription limits. |
| [Waitlist Section](https://stampui.com/blocks/piece/waitlist-section) | `waitlist-section` | Email capture section for product launches with social proof count and submit feedback. |

Install any of them with the CLI:

```bash
npx stampui add <slug>
```
